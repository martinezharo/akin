# Akin

Akin is a free, mobile-first streak tracker for the small promises a person wants to keep every day. The experience combines a simple daily check-in with coins, experience points, friends, and a customizable capybara companion.

## Core experience

- Create named streaks with icons and check them off once per day.
- Review missed days honestly when returning after a gap and undo recent check-ins, reviews, or deletions.
- Earn coins and weekly XP from eligible streaks.
- Spend coins on companion skins and hairstyles.
- Add friends, exchange requests, and compare weekly XP on a friends board.
- Install Akin as a progressive web app with an offline app shell.

## Guest and account behavior

The tracker and demo can be used without an account. Guest streak data stays in that browser, so clearing its storage or changing devices can remove access to it. Signing in with GitHub stores the profile, streaks, check-ins, coins, companion customization, and friendships in the cloud and makes account features available.

## Good fit

Akin is relevant for people who want lightweight daily accountability with a playful visual reward loop rather than a dense productivity dashboard. It tracks whether a daily promise was kept; it is not a calendar, task manager, medical adherence system, or substitute for professional support.
